# 星詞突擊

俯視射擊。主畫面可以選星域或喪屍夜。星域開的是攔截機，敵艦會開火。喪屍夜裡屍群會保持距離遠攻：普通屍單發、跑尸連射、壯屍撒酸。首領或屍王血量掉到鎖點會升起護盾，答對單詞，或 100 以內的加減法，才能繼續扣血、進入下一波。

每一波是一個陣型，不是隨機堆人。首領答完第一題改預判連射，第二題會召一圈小兵。答得快會多扣一截血。撿到的散彈、護盾、加速先存著，自己按才發動。每一波有一隻信標，護罩只留一段缺口，缺口轉到你這邊才打得穿。信標會往下逃，溜走扣分。空白鍵或「貫」打出貫穿彈，無視護罩，八秒一次。打掉信標會再給一次技能。

背景音樂是 CC0：星域 MintoDog《Space Battle》，喪屍夜 SRG774《Pulse》，首領 SRG774《Urgent》。答題時音樂變小。

這一版可以玩，也可以改詞庫。星域用新的攔截機和敵艦。喪屍夜是另一條街，屍群從上方湧下來。

## 現在有什麼

- 敵人波次，三種小兵，每三波一隻首領
- 首領在大約三分之二和三分之一血量鎖盾，答對才解鎖
- 題型：混合、只考單詞、只考數學
- 詞庫可新增、刪除、匯出和匯入 JSON
- 能量：散彈、護盾、加速
- 生命、分數、本機高分、暫停
- 視差星空、槍口閃光
- 鍵盤（WASD / 方向鍵）或滑鼠、觸控拖曳

介面是繁體中文。詞庫和高分存在這台裝置的瀏覽器裡，不會上傳。

## 在電腦上跑

需要 Node.js 22。

```bash
npm install
npm run dev
```

瀏覽器打開終端機印出的位址（預設埠 8080）。
