# 星詞突擊

俯視太空射擊。普通敵人直接打。首領血量掉到鎖點會升起護盾，答對單詞，或 100 以內的加減法，才能繼續扣血、進入下一波。

這一版可以玩，也可以改詞庫。喪屍模式和更好的飛船造型是下一版，還沒進這個提交。

## 現在有什麼

- 敵人波次，三種小兵，每三波一隻首領
- 首領在大約三分之二和三分之一血量鎖盾，答對才解鎖
- 題型：混合、只考單詞、只考數學
- 詞庫可新增、刪除、匯出和匯入 JSON
- 能量：散彈、護盾、加速
- 生命、分數、本機高分、暫停
- 視差星空、槍口閃光
- 鍵盤（WASD / 方向鍵）或滑鼠、觸控拖曳

介面是繁體中文。詞庫和高分存在這台裝置的瀏覽器裡，不會上傳。

## 在電腦上跑

需要 Node.js 22。

```bash
npm install
npm run dev
```

瀏覽器打開終端機印出的位址（預設埠 8080）。

## 裝到手機

這是網頁，不是 App Store 安裝檔。部署或發布後用手機瀏覽器打開網址：

- iPhone：Safari → 分享 → 加入主畫面
- Android：Chrome → 安裝應用程式或加到主畫面
